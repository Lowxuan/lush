# Lush 命令语言规范

版本 0.3.1 · 状态：可实施草案

---

## 0. 摘要

Lush 是一门嵌入 C++ 宿主的命令语言，目标场景是 AutoCAD 式的「命令行 + GUI 深度融合」：

- 一条命令既可以一次写全参数直接执行，也可以在参数不足时进入会话，由命令行或鼠标逐个补齐；
- 语言本身支持变量、列表、Point、条件、循环、引用与函数调用，可编写脚本批量生成操作；
- 语言核心零宿主依赖：解析、求值、命令注册、会话管理都不认识 Qt 或绘图。

本规范只定义**语言与命令框架的契约**，不定义 C++ 头文件形状，也不涉及任何 GUI。

### 0.1 关键决策速览

| # | 决策 |
|---|---|
| D01 | 语句终止符 = 换行 / `;` / `}` / `else` / EOF；`\` 是唯一的显式续行 |
| D02 | Point 是独立类型，维度 2 或 3，坐标恒为 double |
| D03 | 下标从 0 开始 |
| D04 | 唯一列表类型为 `list`，可变；`h = f` 是深拷贝 |
| D05 | 引入 `h = ref f`，引用只能指向变量；赋值永远重绑定；整值写穿透用 `*h = v` |
| D06 | int64 + double；`2/4 == 0`，`2/4.0 == 0.5` |
| D07 | 块引入作用域；`for` 的循环变量出循环即失效 |
| D08 | 调用写法由**位置**决定：语句位置 = 并置命令，表达式位置 = 后缀 `(...)` 调用 |
| D09 | 命令参数按**顶层空白**切词；一元运算符必须贴身；因此 `line a - b` 是语法错误 |
| D10 | `(x,y)` 是 Point 字面量；`[...]` 是 list 字面量；裸 `x,y` 只在命令参数位置作为糖 |
| D11 | 命令与函数共用一张可调用体注册表；函数与类型构造器是一等值，命令不是值 |
| D12 | 交互式会话只允许出现在 REPL 的顶层单条命令语句；脚本必须写全参数 |
| D13 | v1 不实现 `def`/`return`，但保留关键字 |
| D14 | 脚本先整体解析与校验，再执行；运行时错误立即中止 |
| D15 | `type(v)` 返回对应类型的可调用构造器；`type(4.4)(2)` 等价于 `double(2)` |
| D16 | 内建函数、类型构造器、`type` 本身都是 callable 值；命令不是值 |
| D17 | v1 引用单层：被引用的 cell 不能再改绑为引用（R008）；普通赋值仍允许 |
| D18 | REPL 在未闭合括号或行尾 `\`（允许尾随水平空白）时进入 `Incomplete` 续行；脚本模式未闭合括号是 P002，行尾 `\` 是 L005 |

## 2. 词法

### 2.1 源文本

- 编码 UTF-8；允许开头有 U+FEFF BOM，BOM 被忽略。
- BOM 只允许出现在文件开头。BOM 不计入行/列：第一个非 BOM 字符位于 1:1；token 的 offset 仍是包含 BOM 的原始字节偏移。文件中其他位置的 U+FEFF 按非法字符报 L001。
- 换行支持 `\n`、`\r\n`、`\r`，统一视为一个换行。
- 源文本必须是合法 UTF-8，否则词法错误 L001。非法 UTF-8 按字节位置参与“首错”排序（见 10.3）。
- 标识符、关键字、运算符、标点均为 ASCII；字符串可含任意 Unicode。

### 2.2 空白与换行

水平空白：U+0020（空格）、U+0009（制表符）。

换行在词法阶段产生 `NL` token，但有两种抑制：

1. **括号抑制**：词法器维护 `(` 与 `[` 的嵌套深度（不区分两种括号）。深度 > 0 时不产生 `NL`。`{`、`}` 不计入深度。遇到没有对应开启的 `)` / `]` 时深度保持 0，不降到负数；括号匹配错误由语法层报告。
2. **续行抑制**：见 2.3。

`NL` 是否被解析器接受由语法位置决定（见 3.8）。

### 2.3 续行 `\`

在字符串与注释之外，遇到 `\` 时：

1. 向后跳过零个或多个水平空白；
2. 若紧接着一个换行，则把 `\`、这些水平空白、以及换行一起删除，**不产生 `NL` token**；
3. 若转到 EOF，报 L005（续行符位于 EOF）；
4. 否则报 L006（孤立的 `\`）。这里的“否则”包括 `\` 后接水平空白再接 `#` 注释，或接任何非换行字符。

`\` 之前的空白**不受影响**。因此：

```lush
a = 1 + \
2            # 拼成 a = 1 + 2
```

```lush
line f \
g            # 拼成 line f g，仍是两个参数
```

注意：`a\` 后接换行再接 `b` 会拼成标识符 `ab`。要保留分隔，写成 `a \`。

其他规则：

- 字符串里的 `\` 是转义符，不是续行；
- `#` 注释里的 `\` 是普通字符，注释到行尾结束，不续行；
- `\` 后只有水平空白直到 EOF → L005；
- `\` 后接非换行字符（包括 `#` 注释）→ L006；
- 被删除的换行**仍然递增物理行号**，诊断报告物理行/列；
- token 的 offset 始终指向原始源文本，便于行列映射。

### 2.4 注释

`#` 到行尾为注释。注释不产生 token。字符串里的 `#` 是普通字符。无块注释。注释不包含行尾换行；换行仍产生 `NL`（除非被 2.2 的规则抑制）。

### 2.5 标识符、关键字、大小写

标识符：

```
[A-Za-z_][A-Za-z0-9_]*
```

关键字（大小写不敏感）：

```
if  else  while  for  in  true  false  ref  break  continue  def  return
```

规则：

- 关键字：大小写不敏感（`IF`、`True` 均可）。
- 词法阶段保留标识符/关键字的原始拼写；关键字匹配与命令查找才做大小写不敏感比较。
- 命令/函数名：查找时大小写不敏感，但保留注册时的规范拼写用于显示。
- 变量名：大小写敏感。
- 变量名不得与关键字或已注册的命令/函数名（大小写不敏感比较）相同，赋值时报 S003。

### 2.6 数值字面量

整数：十进制 `[0-9]+`，类型 `int`，范围 `[-2^63, 2^63-1]`。

浮点数：必须小数点两侧都有数字，可选指数：

```
[0-9]+ "." [0-9]+ ( [eE] [+-]? [0-9]+ )?
[0-9]+ [eE] [+-]? [0-9]+
```

- `1.0`、`3.2343`、`1e3`、`1.0e-3` 合法；
- `1.`、`.5`、`1e`、`1e+`、`1.e3` 非法（L004）；
- 以数字开头的数值必须构成完整的整数或浮点数。紧跟数值的 ASCII 标识符字符、`_`、额外的 `.` 或非法指数属于非法数值延续，整个单元报 L004，不拆成“数字 + 标识符”；合法的 `e` / `E` 指数除外。例如 `123abc`、`1_000`、`0x10`、`1.foo`、`1..2` 都报 L004；
- 数值在分隔符处正常结束，分隔符不参与数值：水平空白、换行、`#`、`,`、`;`、`(`、`)`、`[`、`]`、`{`、`}`、`:`、`?` 以及运算符。`.` 与 `e` / `E` 是例外：紧跟数值时必须构成合法的小数/指数，否则 L004；
- 不支持十六进制、下划线分隔；出现即 L004；
- 浮点字面量必须是有限 double；上溢到 ±Inf 或下溢超出 double 可表示范围都报 L004（如 `1e309`、`1e-400`）；
- 字面量不带符号，负号是单目运算符；
- 十进制整数的**绝对值**必须 ≤ `2^63`；`> 2^63` 直接 L004。

**INT64_MIN 的折叠规则**

int64 的正负范围不对称（`[-2^63, 2^63-1]`），而语言没有负数字面量，所以 `2^63` 这个"刚好越界"的字面量必须特殊处理：

1. 词法：绝对值等于 `2^63` 时产生一个**边界字面量**标记，不立即报错；
2. 语法：边界字面量只有在**（可带括号的）单目 `-` 的直接操作数**位置才折叠为 INT64_MIN；
3. 其它任何位置 → L004。

```lush
-9223372036854775808      # INT64_MIN
-(9223372036854775808)    # INT64_MIN
 9223372036854775808      # L004
0 - 9223372036854775808   # L004（二元减法不折叠）
-9223372036854775809      # L004
--9223372036854775808     # 内层 INT64_MIN，外层取负溢出 → R005
```

### 2.7 字符串字面量

只使用双引号，单行。转义序列：

| 转义 | 含义 |
|---|---|
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 制表符 |
| `\0` | NUL |
| `\uXXXX` | Unicode 码点（4 位十六进制；代理区非法） |

- 字符串在遇到换行或 EOF 前未闭合 → L002；
- 未知转义 → L003；
- 字符串内的 `\` 后紧跟换行 → L003（续行只发生在字符串外）；
- `\uXXXX` 必须恰好 4 位十六进制；非法十六进制数字报 L003，后面多余的十六进制字符按普通字符继续；
- 不合并 UTF-16 代理对：`\uD800`–`\uDFFF` 均报 L003，`\uD83D\uDE00` 也不例外；
- 字符串按 Unicode 码点处理：`len(s)` 返回码点数，`s[i]` 返回第 i 个码点组成的字符串。

### 2.8 运算符与标点

```
(  )  [  ]  {  }  ,  ;  :  ?  .
=  ==  !=  <  <=  >  >=  +  -  *  /  %  !  &&  ||  ++  --
```

`\` 只用于续行（2.3），不参与表达式。

词法器按最长匹配识别运算符和标点（如 `==` 优先于 `=`，`++` 优先于 `+`）。

### 2.9 词法错误

| 码 | 含义 |
|---|---|
| L001 | 非法字符 / 非法 UTF-8 |
| L002 | 字符串未闭合（含裸换行或 EOF） |
| L003 | 未知转义（含字符串内 `\` 后换行、非法 `\u`、代理区） |
| L004 | 数值字面量格式错误或越界（含浮点超出 double 范围） |
| L005 | 续行符后只有水平空白直到 EOF |
| L006 | 孤立的 `\`（后接非换行字符，包括 `#` 注释） |

## 3. 语法

### 3.1 程序、语句与终止

一个程序是语句序列。语句之间用以下之一分隔：

```
NL | ; | } | else | EOF
```

其中 `}`、`else`、EOF 是**隐式终止**（不消费成语句的一部分）；`NL` 与 `;` 由语句消费。连续的空语句（多余换行、`;`）合法。

顶层与块内都允许空行。控制语句（`if`/`while`/`for`/块）作为一个整体，同样要与下一条语句分隔；紧邻 `}` 或 EOF 时除外。

### 3.2 语句形式

只有以下形式是语句：

1. 块：`{ stmt* }`
2. 条件：`if ( expr ) stmt [ else stmt ]`
3. 循环：`while ( expr ) stmt`
4. 循环：`for IDENT in expr stmt` 或 `for ( [IDENT = expr] ; [expr] ; [expr] ) stmt`
5. 跳转：`break` / `continue`
6. 赋值：`lvalue = expr`
7. 引用赋值：`IDENT = ref IDENT`
8. 命令：`IDENT word*`

**裸表达式不是语句。** 这是硬性规定，否则 `line` 单独一行会被解释成"读取变量 line"，永远无法进入交互命令。

### 3.3 表达式与优先级

从低到高：

| 级别 | 运算符 | 结合性 |
|---|---|---|
| 1 | `?:` | 右结合 |
| 2 | `\|\|` | 左结合 |
| 3 | `&&` | 左结合 |
| 4 | `==` `!=` | 左结合 |
| 5 | `<` `<=` `>` `>=` | 左结合 |
| 6 | `+` `-` | 左结合 |
| 7 | `*` `/` `%` | 左结合 |
| 8 | 前缀 `-` `!` `*` `++` `--` | 右结合 |
| 9 | 后缀 `[expr]` `.IDENT` `(args)` `++` `--` | 左结合 |
| 10 | 原子 | — |

- `*` 在第 7 级是乘法，在第 8 级是解引用；由位置区分。
- 解引用的操作数只能是变量名：`*h`。`*h[0]` 非法，请写 `h[0]`。
- `++` / `--` 的操作数必须是可赋值目标。
- 赋值不是表达式：`a = b = c` 非法。
- 三元只求值被选中的分支。
- **所有后缀运算符必须紧贴左操作数**：`a[0]`、`p.x`、`f(x)`、`i++` 合法；`a [0]`、`p .x`、`f (x)`、`i ++` 都不构成后缀运算。
- **调用是后缀**：任意表达式紧贴 `(` 即可调用；callee 必须是 callable，否则 R012。

原子：

- `INT`、`FLOAT`、`STRING`、`true`、`false`
- `IDENT`：变量；若该名字是已注册的函数/类型构造器，则是 callable 值；若是命令名 → S008
- `( expr )`：分组
- `( expr , expr [ , expr ] )`：Point 字面量（2 或 3 个坐标）
- `[ [expr {, expr}] ]`：list 字面量

调用括号与 Point 括号的区分：

> **调用是后缀：callee 紧贴 `(`。调用括号内，顶层逗号是参数分隔符；其他位置的 `(a,b)` 是 Point。**
> `f(1,2)` 是 2 个参数；`f((1,2))` 是 1 个 Point 参数；`type(4.4)(2)` 先取 `double` 再调用它。

### 3.4 命令参数：切词规则

命令语句的形式是：

```
IDENT word*
```

名称之后、直到语句终止符为止的 token，按**顶层空白**切分成词：

- 顶层 = `(` 与 `[` 的嵌套深度为 0；
- 一个新词开始于：第一个 token，或任意一个 `wsBefore == true` 且深度为 0 的 token；
- 括号内部（深度 > 0）的空白不切词；
- 每个词必须被完整解析为 `barePoint` 或 `expr`，不允许残留 token。

`wsBefore` 的精确定义：在经过 2.3 的续行删除后的逻辑文本中，从当前 token 的起点向左看，紧邻的字符是空格或 tab 时为 `true`，否则为 `false`。行首缩进因此计入；换行本身不是水平空白，换行后没有缩进则为 `false`；文件第一个 token 若无前导空白为 `false`。注释字符不是空白，但注释前后的空格/tab 按普通字符处理。`NL` 与 EOF 的 `wsBefore` 固定为 `false`。

因此 `a \` 换行 `b` 中 `a` 后的空格保留，`b.wsBefore == true`；`a\` 换行 `b` 拼成标识符 `ab`，不产生两个 token。

推论：

- `line f g` → 两个词 `f`、`g`；
- `line 0,0 1,1` → 两个词；
- `line (0, 0) (1, 1)` → 两个词（括号内空格不切）；
- `line a+b c` → 两个词；
- `line a - b` → 三个词 `a`、`-`、`b`，`-` 无法构成表达式 → 语法错误 P004；
- 在参数顶层，一元运算符必须紧贴操作数，所以 `line -1 -2` 是 `-1` 与 `-2` 两个词；括号内允许 `(- 1)`；
- 调用必须紧贴：`f(x)`、`type(1)(2)`；`f (x)` 在参数位置是两个词，在表达式位置是语法错误；
- 参数里的复杂表达式请整体加括号，括号内空白随意：`line (a + b, c) (d, e)`。

**注意**：命令名与第一个词可以紧邻，`line(1,2)` 等价于 `line (1,2)`：语句位置没有调用语法，`(` 只是第一个词的开始。

### 3.5 裸坐标糖

仅在命令参数位置，一个词可以整体解析为裸 Point：

```
barePoint = simple ( "," simple ){1,2}
simple    = "-"? atom suffix*
atom      = INT | FLOAT | IDENT | "(" expr ")"
suffix    = "[" expr "]" | "." IDENT | "(" [args] ")"
```

后缀同样必须紧贴：`f(1,2),3` 是一个裸坐标（第一维是调用结果），`f (1,2),3` 会被空白切词。

- 坐标个数必须是 2 或 3；
- 逗号两侧不能有空白（空白会先切词）；
- 每个坐标必须是 int 或 double，转换时统一变为 double；
- 坐标本身不能是 Point 字面量：`(1,2),3` 是语法错误 P004；
- `1,2`、`-1,-1`、`p.x,p.y`、`(a+1),b` 合法；
- `1, 2` 会切成 `1,` 与 `2`，`1,` 非法 → P004。

裸坐标与括号 Point 等价：`line 1,2 3,4` ≡ `line (1,2) (3,4)` ≡ `line (1, 2) (3, 4)`。

注意：任何命令参数位置都会**优先尝试**裸坐标，因此 `move 1,2` 是一个 Point 而不是两个数值；需要两个数值参数时写 `move 1 2`。

### 3.6 Point 与 list 字面量

| 写法 | 类型 |
|---|---|
| `(1,2)` | Point2 |
| `(1,2,3)` | Point3 |
| `(1)` | 分组，值为 int 1 |
| `(1,2,3,4)` | 语法错误 P003（提示改用 `[1,2,3,4]`） |
| `[]` | 空 list |
| `[1,"a",(2,3)]` | 异构 list |

- Point 坐标必须是 int/double，构造时统一为 double；坐标不是数值 → R006；
- list 元素类型不限；
- 两个字面量都不允许尾随逗号；
- `(a,b)` 中的 `a`、`b` 可以是任意表达式（含空格），因为括号抑制换行且不切词。

### 3.7 语句 / 表达式判定

解析器在**语句位置**按以下确定性过程判定：

1. `{` → 块。
2. 关键字 `if` / `while` / `for` / `break` / `continue` / `def` / `return` → 对应语句；`def`/`return` 报 S007。
3. `*` → 赋值语句，解析 `*IDENT`，随后必须是 `=`。
4. `IDENT`：
   1. 尝试解析**连续的**可赋值路径：`IDENT` 后紧跟（无空白）`[...]` 或 `.IDENT`；
   2. 若路径之后是 `=` → 赋值语句；若 RHS 是 `ref IDENT` → 引用赋值；
   3. 否则回退到路径起点之后，按命令语句解析：`IDENT` 是命令名，其余按切词规则成为参数。

在**表达式位置**：

- 任意表达式后紧跟 `(` → 调用；callee 必须是 callable（否则 R012）；
- `IDENT` → 变量；若该名字是已注册的函数/类型构造器，则是 callable 值；若是命令名 → S008；
- `(` → Point 或分组（看顶层逗号个数）；
- `[` → list。

调用可以链式：`type(4.4)(2)` 解析为 `(type(4.4))(2)`；中间有空白则不是调用（`type(4.4) (2)` → P001）。

路径必须"连续"这一条很重要：`p.x = 5` 是赋值，`p .x = 5` 不是（第二个 token 有前导空白，路径在 `p` 处结束，随后不是 `=`，于是按命令解析并报错）。

### 3.8 换行可省略的位置

解析器在以下位置跳过 `NL`：

- 程序开头、语句之间、块内空行；
- `{` 之后、`}` 之前；
- `if (...)` / `while (...)` / `for (...)` 的 `)` 之后；
- `else` 之前与之后。

因此以下都合法：

```lush
if (a)
{
    ...
}
else
{
    ...
}
```

```lush
if (a)
line 0,0 1,1
```

块内语句仍然需要 `NL` 或 `;` 分隔（紧邻 `}` 的语句除外）。

### 3.9 语法错误

| 码 | 含义 |
|---|---|
| P001 | 意外的 token |
| P002 | 意外的文件结束 |
| P003 | Point 字面量元素个数不是 2 或 3 |
| P004 | 命令参数不是合法表达式 |
| P005 | 括号不匹配 |
| P006 | 语句缺少终止符 |

未闭合的 `{`/`(`/`[` 在脚本 EOF 上归入 P002；REPL 将其视为 `Incomplete`（见 10.2）。

## 4. 类型与值

### 4.1 类型

| 类型 | 说明 |
|---|---|
| `int` | 有符号 64 位整数 |
| `double` | IEEE-754 双精度；不接受 NaN / ±Inf |
| `bool` | `true` / `false` |
| `string` | UTF-8 字符串，按码点索引 |
| `list` | 异构、可变、值语义 |
| `point` | 2 或 3 维，坐标恒为 double |
| `type` | 可调用值（函数/类型构造器）的类型；`type` 本身也是 callable |

`ref` 不是一等类型：它只能作为变量的当前内容存在，不能进入 list、Point、命令参数或返回值（见 4.5）。

`void` 只描述"没有返回值"，不是值。

`type` 既是可调用值的类型名，也是一个内建 callable（返回参数的类型构造器）。`int`、`double`、`bool`、`string`、`list`、`point`、`type`、`len` 都是 callable 值；其中前六个是数据类型的构造器，`type` 是元类型兼查询函数，`len` 是普通函数。callable 值可以存入变量/list、作为 `ref` 目标、作为命令的 `any` 参数，但不能参与算术或大小比较（见 4.7）。

### 4.2 Point

- 维度在创建时固定为 2 或 3；`len(p)` 返回维度。
- `p.x` / `p.y` / `p.z` 是 `p[0]` / `p[1]` / `p[2]` 的糖；2 维点访问 `.z` 或 `p[2]` 报 R003。
- 分量可写：`p[0] = 1`、`p.y = 2`，写入的 int 会转成 double。
- 成员只读：`p.length` 不存在（用 `len(p)`）。

### 4.3 list

- 异构：`[1, "a", (2,3), [4]]` 合法。
- 可变：`a[0] = 1`、`a[1][0] = 9`。
- 派生成员：`a.length`（只读，等价于 `len(a)`）。
- 没有切片、没有 `+` 拼接、没有内建排序（v1）。

### 4.4 值语义与拷贝

**读取任何表达式都得到一个独立的值。** 具体地：

- 读取变量：拷贝其值（深拷贝）；
- 读取 `a[i]`：拷贝该元素；
- 赋值、命令/函数参数绑定、list/Point 字面量构造：都发生拷贝；
- 因此 `h = f` 之后修改 `h` 不影响 `f`；嵌套 list 同样独立；
- callable 值（类型为 `type`）不可变，拷贝等价于复制引用（身份不变）。

`ref` 是唯一的别名机制。

> 性能说明：v1 采用朴素深拷贝；大列表在热循环里请用 `ref`。未来可在不改语义的前提下引入 COW。

### 4.5 ref

语法上只有一种引用赋值：

```lush
h = ref f
```

约束：

1. 左侧必须是**简单变量名**；`a[0] = ref f`、`p.x = ref f` 非法（S004）。
2. 右侧必须是简单变量名；`ref 1`、`ref f[0]` 非法（S004）；名字未绑定 → R001。
3. 若右侧变量当前已经持有引用 → R008（不允许引用的引用）。
4. 引用指向**变量的单元（cell）**，不是指向值。变量后来被重新赋值，引用看到新值。
5. 左侧的名字按 6.1 的目标解析规则处理：写入最近的同名绑定，不存在则在当前作用域创建。
6. 每个 Cell 带 `hasInboundRef` 标记。`h = ref f` 成功后，`f` 的 cell 被标记为 true。
7. 若某 cell 的 `hasInboundRef == true`，它不能再被改绑为引用：`f = ref g` → R008；普通赋值 `f = v` 仍然允许，`h` 会看到新值。
8. 自引用：`h` 已绑定时执行 `h = ref h` → R008。
9. 引用赋值先校验右侧，再解析/创建左侧；因此 `h = ref h` 在 `h` 未绑定时是 R001，已绑定时是 R008。
10. 因为上述规则，引用最多一层；读取时只需跟随一次，不需要递归或环检测。

语义表：

| 写法 | 行为 |
|---|---|
| `h = ref f` | 让 `h` 成为 `f` 的别名 |
| 读 `h` | 解引用后拷贝值 |
| `h[i] = v` | 通过引用写 `f` 的元素 |
| `h.m = v` | 通过引用写 `f` 的成员 |
| `h++` / `h--` | 通过引用读改写 |
| `*h = v` | 用 `v` 整体替换 `f` 的值 |
| `h = v` | **重绑定** `h` 为普通值，`f` 不变 |
| `h = ref g` | 重绑定 `h` 到 `g`；若 `h` 已被其它引用指向 → R008 |
| `*h`（右值） | 等价于读 `h` |

解析器在看到 `=` 后紧跟关键字 `ref` 时进入引用赋值形式；`ref` 出现在其它位置 → S004。

其他规则：

- 引用不是一等值：`echo h`、`h + 1`、`f(h)`、`[h]` 都先解引用；
- `type(h)` 返回被引用值的类型构造器，永远不返回 `ref`；
- 引用持有 cell 的所有权，因此局部变量离开作用域不会悬空；
- `for i in` 每轮创建**新 cell**，引用可安全逃逸到循环外；
- C 风格 `for(i=...)` 的 `i` 在整个循环期间是**同一个 cell**，引用会看到最终值。
- `hasInboundRef` 不会被清除：v1 保守地认为"曾经被引用过"的 cell 不能再改绑为引用，即使引用已经离开作用域。

### 4.6 隐式转换

只允许两种隐式转换：

1. `int → double`：混合数值运算、写入 Point 分量、绑定 `number` 参数、`point(...)` 构造。
2. `list → point`：仅发生在**期望 Point 的位置**（命令/函数参数声明为 `point`，或 `point(v)` 的单参数形式）。要求长度 2 或 3，且每个元素是 int/double；全部转成 double，否则 R006。

不存在 `bool ↔ int`、`string ↔ number`、`point ↔ list`（后者只能显式 `point(v)` 或参数绑定）。callable 不参与任何隐式转换。

赋值不转换：`p = [1,2]` 之后 `p` 仍是 list。

### 4.7 相等与排序

`==` / `!=`：

- 数值之间先提升到 double 比较（`1 == 1.0` 为 true）；超过 2^53 的 int 与 double 混合比较可能丢精度，这是已知限制；两个 int 之间按整数精确比较；
- bool 只能与 bool；
- string 按码点逐位比较；
- Point 要求同维度，逐坐标比较；
- list 要求同长度，逐元素递归比较；
- callable 按**身份**比较：`type(4.4) == double` 为 true，`type(1) == double` 为 false；
- 其它跨类型比较 → R002。

`<` `<=` `>` `>=`：

- 数值之间；
- string 之间按码点字典序；
- bool、list、Point、callable → R002。

### 4.8 真值

**条件必须是 bool。** `if (1)`、`while ("x")` 一律 R002。`&&` / `||` / `!` 的操作数也必须是 bool。

## 5. 运算语义

### 5.1 算术

| 运算 | 允许的类型 | 结果 |
|---|---|---|
| `a + b` | int/int, 任一 double | 数值，提升到 double |
| `a + b` | string/string | 拼接 |
| `a + b` | point/point（同维） | 逐坐标相加 |
| `a - b` | 数值 | 数值 |
| `a - b` | point/point（同维） | 逐坐标相减 |
| `-a` | 数值 | 数值 |
| `-a` | point | 逐坐标取反 |
| `a * b` | 数值 | 数值 |
| `a * b` | point × 数值，数值 × point | 逐坐标缩放 |
| `a / b` | 数值 | 数值 |
| `a / b` | point / 数值 | 逐坐标缩放 |
| `a % b` | int/int | 截断余数，符号随被除数 |
| `++` / `--` | int 可赋值目标 | 前缀返回新值，后缀返回旧值 |

不允许：point 与标量相加、point 乘 point、point 取模、list 参与任何算术、callable 参与任何算术或大小比较（只允许 `==`/`!=`）。

整数除法向零截断：`-3/2 == -1`。任何除零（含 `0.0`）→ R004。

### 5.2 逻辑与比较

- `&&` / `||`：bool × bool → bool，短路求值；
- `!`：bool → bool；
- 比较结果恒为 bool。

### 5.3 索引与成员

| 接收者 | 索引/成员 | 结果 | 可写 |
|---|---|---|---|
| `list` | `[int]` | 元素（拷贝） | 是 |
| `string` | `[int]` | 单码点字符串 | 否 |
| `point` | `[0/1/2]` | double | 是 |
| `point` | `.x` / `.y` / `.z` | double | 是（`.z` 仅 3 维） |
| `list` / `string` | `.length` | int | 否 |
| 其它 | 任意 | R002 | — |

索引必须是 int（double 不隐式转 int）。负索引与越界 → R003。对只读位置（string 元素、`.length`）赋值 → R002。

### 5.4 自增自减

- 只接受 int 类型的可赋值目标：变量、元素、成员（经引用时写穿透）；
- 溢出 → R005；
- `++` 可以出现在表达式中：`x = i++`。

### 5.5 三元

`cond ? a : b`：`cond` 必须是 bool；只求值被选中的分支；两个分支类型不必相同。

### 5.6 溢出与浮点

- int 的 `+ - * / %`、单目 `-`、`++ --` 全部做溢出检查，越界 → R005；
- `INT64_MIN / -1` → R005；
- double 运算产生 NaN 或 ±Inf → R009；
- 不支持 NaN 字面量或比较。

## 6. 语句语义

### 6.1 赋值与作用域

- 变量无需声明，首次赋值即在**当前作用域**创建。
- 赋值目标解析顺序：从内到外查找最近的同名绑定；找到则写入该绑定，找不到则在当前作用域创建。
- “写入绑定”指替换该绑定**自身**的值：即使它当前持有引用，`h = v` 也只改变 `h`，不写穿到 `h` 指向的目标；要写穿请用 `*h = v`、`h[i] = v` 或 `h.m = v`。
- 因此内层块里 `x = 2` 会更新外层可见的 `x`，而不是新建局部变量。
- 唯一能"遮蔽"的情况是 `for` 的循环变量（它在 for 作用域新建绑定）。
- 作用域：
  - 程序 = 全局作用域；
  - 每个 `{}` 块在每次进入时创建新作用域；
  - `for` 创建一个作用域容纳循环变量与循环体；
  - 无花括号的语句体不创建新作用域（共享外层，循环变量除外）。
- 块结束时移除该层名字绑定；被引用持有的 cell 继续存活。

### 6.2 if

`if (cond) stmt [else stmt]`：`cond` 必须 bool；`else` 绑定最近的未配对 `if`。then 语句与 `else` 之间允许换行和空语句 `;`：

```lush
if (a) x = 1; else x = 2
if (a) x = 1
else x = 2
```

### 6.3 while

`while (cond) stmt`：每轮重新求值 `cond`；`cond` 必须 bool。

### 6.4 for

**for-in：**

```lush
for i in expr stmt
```

- `expr` 在**外层作用域**求值一次，得到一个值（值语义，天然是快照），然后才创建循环变量；
- 可迭代类型：list（逐元素）、string（逐码点）；Point 与其它类型 → R002；
- 每轮为 `i` 创建**新 cell**，元素拷贝进 `i`；
- `i` 在循环结束后不可见。

**C 风格：**

```lush
for (i = 0; i < n; i++) stmt
```

- init 槽只允许 `IDENT = expr` 或空；
- 有 init 时，先在**外层作用域**求值右侧，再在 for 作用域新建 `i` 并赋值（即使外层已有同名变量，也遮蔽）；
- init、cond、step 都可以为空；cond 为空视为永远真；
- `i` 在整个循环期间是同一个 cell；
- `i` 在循环结束后不可见；init 为空时，cond/step 中引用的名字按普通作用域解析。

### 6.5 break / continue

- `break` 跳出最内层循环；
- `continue` 进入最内层循环的下一轮；在 C 风格 `for` 中先执行 step 子句，再判断 cond；
- 不在循环内 → S005。

### 6.6 块

`{ ... }` 是语句，引入新作用域。块可以单独出现。

### 6.7 命令语句

`IDENT word*`：

- 名称按大小写不敏感查找注册表；
- 参数按 3.4 切词并求值，从左到右；
- 再按参数的声明类型做绑定转换（7.2）；
- 函数有返回值（作为语句调用时丢弃）；函数名在表达式位置是 callable 值；
- 未注册的名字 → S001；
- 参数个数不符 → S002；交互命令缺参且不满足会话条件 → S006；
- 命令不能出现在表达式位置 → S008。

## 7. 命令系统

### 7.1 注册表

```text
CommandSpec {
    name        : string          // 规范拼写，大小写不敏感唯一
    aliases     : [string]
    params      : [ParamSpec]     // 顺序即位置参数顺序
    returns     : void | value
    interactive : bool            // 仅 void 命令可为 true
    help        : string
}

ParamSpec {
    name        : string
    type        : int | number | point | string | bool | list | any
    dim         : 0 | 2 | 3       // 仅 point 有意义，0 = 不限
    optional    : bool
    default     : 字面量          // optional 时必填
    variadic    : bool
    hint        : string          // 交互提示与补全说明
}
```

注册约束：

- 名称与别名不得是关键字；
- 名称与别名大小写不敏感唯一；
- 必选参数必须排在可选参数之前；
- 变参必须是最后一个参数，且不能再有可选参数；
- 默认值必须能通过该参数的类型绑定；
- 注册应在执行脚本/开始会话之前完成；脚本内不能注册。
- `returns = value` 的可调用体有值形态（callable）；`returns = void` 的命令只能作为语句，没有值形态。

### 7.2 参数绑定与转换

| 声明类型 | 接受的值 | 绑定结果 |
|---|---|---|
| `int` | int | int |
| `number` | int / double | double（int 提升） |
| `point` | point（维度需满足 `dim`） | point |
| `point` | list（长度 2/3、元素数值） | point（坐标转 double） |
| `string` | string | string |
| `bool` | bool | bool |
| `list` | list | list |
| `any` | 除 void/ref 外任意（含 callable） | 原值 |

其余情况 → R002（带参数名与期望类型）。

### 7.3 元数与变参

- 必选参数个数 `R`，参数总数 `N`（不含变参）；
- `argc < R` → 参数不足（是否进入会话见 7.4）；
- `argc > N`（非变参）→ 参数过多；
- 变参吞掉剩余全部参数，逐个按变参类型绑定；
- 可选参数缺省时使用 `default`。

### 7.4 交互式会话

只有满足以下全部条件时，参数不足才进入会话：

1. 当前处于**行模式（REPL）**，而非脚本模式；
2. 本次输入在**顶层**；
3. 整个输入恰好是**一条命令语句**（允许结尾空语句/注释）；
4. 该命令 `interactive == true`。

否则（不满足会话条件）→ S006；非交互命令参数不足、或任何命令参数过多 → S002。

驱动返回四种状态：

```text
DONE | NEED_INPUT(prompt, type, dim, index) | ERROR(diagnostic) | CANCELLED
```

会话行为：

- 已提供的参数按顺序求值并绑定；
- 对第一个缺失参数返回 `NEED_INPUT`，携带 `prompt`（`hint`，缺省用参数名）、期望类型、维度、参数序号；
- 会话模式下，后续每一行输入按 `barePoint | expr` 解析（与命令参数同一规则），例如 Point 参数可直接输入 `0,0`；
- 表达式错误只报错并停留在当前参数，不结束会话；
- 必选参数全部绑定后，若还有可选参数，逐个提示 `hint [default]`；
- 空输入：当前参数是可选参数时采用默认值，其余可选参数一并取默认值并立即完成会话；当前参数是必选参数时取消会话（R011）；
- 宿主可随时 `cancel()`；取消不调用命令；
- 宿主的鼠标点选可以直接提交一个 Point，不必经过文本解析；
- 全部参数绑定后调用命令，返回 `DONE`；
- 命令的副作用由宿主负责，核心不做回滚。

示例：

```text
> line
指定第一个点：0,0
指定第二个点：1,1
LINE (0, 0) (1, 1)
```

### 7.5 与变量命名空间

命令与函数共用一张可调用体注册表；变量存放在独立的作用域链中。语法位置决定调用写法：

- 语句位置：`name arg arg ...` 解析为可调用体，返回值（若有）丢弃；
- 表达式位置：`name(...)` 是调用；裸 `name` 若是函数名则是 callable 值，若是命令名 → S008，否则是变量；
- 变量名不得与已注册名称冲突（S003）；
- 类型构造器与内建函数是一等值，可存入变量/list，可作为参数传递。

### 7.6 参考宿主（仅用于测试）

规范定义以下可调用体，作为 golden tests 的基准；真实宿主可自由替换。`line`、`circle`、`move` 不属于语言核心，核心只内置 `echo`。

| 名称 | 类型 | 交互 | 签名 | 输出 |
|---|---|---|---|---|
| `line` | 命令 | 是 | (p1: point dim2, p2: point dim2) | `LINE <p1> <p2>` |
| `circle` | 命令 | 是 | (c: point dim2, r: number) | `CIRCLE <c> <r>` |
| `move` | 命令 | 否 | (dx: number, dy: number) | `MOVE <dx> <dy>` |
| `echo` | 命令 | 否 | (v: any ...) | 值以单空格连接后换行 |

交互提示：

- `line.p1` = `指定第一个点`，`line.p2` = `指定第二个点`
- `circle.c` = `指定圆心`，`circle.r` = `指定半径`

## 8. 内建

### 8.1 函数（一等 callable）

以下都是 callable 值，可以存进变量/list、作为参数传递；它们的类型都是 `type`。

| 名称 | 签名 | 说明 |
|---|---|---|
| `int` | `(int\|double)` | double 向零截断；越界 R005 |
| `double` | `(int\|double)` | int 提升（可能丢精度） |
| `bool` | `(bool\|int\|double\|string\|list)` | 显式真值转换：`0`/`0.0`/`""`/`[]` → false；非空 → true；Point → R002 |
| `string` | `(any)` | 按第 9 节格式化为 string；`str` 是同一 callable 的别名 |
| `list` | `(list\|string\|point)` | list 深拷贝；string 逐码点；point 取坐标；其它 R002 |
| `point` | `(v)` / `(x,y)` / `(x,y,z)` | 由 list/Point 复制，或由数值构造 |
| `type` | `(any)` | 返回该值的类型构造器；callable → `type` |
| `len` | `(list\|string\|point)` | list 长度、string 码点数、point 维度 |

`type` 的返回值就是对应的 callable 本身：

```lush
type(4.4) == double      # true
type(4.4)(2)             # 2.0
type(1) == int           # true
type("a") == string      # true
type(true) == bool       # true
type([1]) == list        # true
type((1,2)) == point     # true
type(len) == type        # true
type(type) == type       # true
```

`bool(v)` 是**显式转换**，不改变 4.8 的规则：`if (0)` 仍然 R002，必须写 `if (bool(0))`。

`point(v)` 中 `v` 为 list 时执行 4.6 的 `list → point` 转换。

`str(v)` 与 `string(v)` 是同一个 callable；规范文本使用 `string`，`str` 仅作为别名保留。

### 8.2 命令

| 名称 | 签名 | 说明 |
|---|---|---|
| `echo` | `(any ...)` | 无参数时只输出换行 |

## 9. 格式化

`string(v)`（别名 `str(v)`）与 `echo` 使用同一套格式：

| 类型 | 格式 | 示例 |
|---|---|---|
| int | 十进制 | `42` |
| double | 最短可往返表示；整值不带 `.0` | `0.5`、`1`、`1e+20` |
| bool | `true` / `false` | `true` |
| string | 顶层原样；嵌套加引号并转义 | `abc`、`["a", "b"]` |
| point | `(x, y)` 或 `(x, y, z)` | `(1, 2)` |
| list | `[a, b, c]`，空为 `[]` | `[1, [2, 3]]` |
| callable（`type` 值） | callable 的名字 | `int`、`double`、`len` |

- `echo a b c` 输出 `a b c\n`；
- `echo` 对 string 参数输出原文（不含引号）；
- list/Point 内部的 string 加双引号，并转义 `\`、`"`、换行、制表符与控制字符；
- `-0.0` 输出 `0`；
- 不存在 NaN/Inf，因此无需特殊格式。

## 10. 执行模型

### 10.1 脚本模式

1. 词法 + 语法 + 校验整个程序；
2. 任一阶段出错 → 不执行任何语句，返回第一个错误；
3. 校验通过后顺序执行；
4. 运行时错误立即中止，已产生的输出与命令副作用保留；
5. EOF 时仍有未闭合的 `{`/`(`/`[` → P002。

脚本模式**不进入交互会话**：任何参数不足一律 S002。

校验阶段检查：未知命令、参数个数、保留名赋值、`ref` 语法、`break/continue` 位置、交互命令是否顶层单条、`def/return` 未实现。

### 10.2 行模式 / REPL

- Env 跨行保留；
- 解析器在输入末尾仍处于未闭合的 `{`/`(`/`[`，或最后一行以 `\` 后跟零个或多个水平空白结束时，返回 `Incomplete`；REPL 以 `... ` 继续读取，直到完整或用户取消；
- 完整后按累积缓冲区解析并执行；
- 满足 7.4 条件时进入会话；
- 出错返回提示符，Env 不变（已发生的副作用不回滚）；
- 空行是空语句。

脚本模式不续行：未闭合括号在 EOF 上是 P002；行尾 `\` 按 2.3 报 L005。

### 10.3 错误策略

| 阶段 | 策略 |
|---|---|
| 词法/语法/校验 | 首错中止，整段不执行 |
| 运行时 | 首错中止当前执行 |
| 会话 | 表达式错误停留当前参数；取消结束会话 |

词法整体成功后才进入语法/校验。词法阶段内部按源文本位置报告第一个错误：非法 UTF-8 按其第一个非法字节的位置参与排序，不会无条件覆盖更早的词法错误。

### 11.2 格式

```text
error[P004]: 命令参数不是合法的表达式
  --> 3:6
   |
 3 | move a - b
   |        ^
   = help: 运算符必须紧贴左操作数，或把整个表达式括起来
```

- 行列均为 1 基，列按 Unicode 码点计数；BOM 不计入列；被续行删除的换行仍按物理行计数；
- 制表符按 1 列计，caret 可能不与显示对齐；
- 每条诊断带字节区间 `[start, end)`；
- 可选 `help` 给修复建议；
- 错误码、位置和字节区间是契约；消息文案可调整，测试不应依赖完整措辞。

## 12. 补全契约

补全引擎必须复用同一套词法与切词规则，禁止另写一套扫描器。

### 12.1 上下文与候选

| 光标位置 | 候选 |
|---|---|
| 语句开头 | 关键字、可见变量、已注册命令/函数 |
| 表达式位置 | 可见变量、callable（函数/类型构造器）、字面量 |
| 命令参数第 k 个 | 按 `params[k]` 的类型/维度过滤可见变量；`any` 参数额外列出 callable；附 `hint` |
| `for i in ` | 可迭代表达式 |
| `[` 或 `[expr,` 内 | 表达式 |
| `(` 内（Point/分组） | 表达式 |
| `f(` / `t(` 内 | 该 callable 的参数类型约束 |
| `.` 后 | `point` → `x/y/z`；`list`/`string` → `length`；callable → 无成员 |
| 会话中 | 当前缺失参数的类型/维度，附 `prompt` |

### 12.2 匹配与插入

- 关键字、命令/函数/类型构造器名：大小写不敏感前缀匹配；
- 变量：大小写敏感前缀匹配；
- 命令参数位置：类型不匹配的变量可降权但仍显示（附类型标签）；
- 候选携带：插入文本、类型、来源（keyword/command/function/type/variable/member）、签名或详情；
- 补全不得改变语义：在 `line 1,2 ` 处应建议 Point 类型变量与 `(`，而不是数字。

### 12.3 提示（非补全）

- 命令缺参时，提示文本来自 `ParamSpec.hint`；
- 可为 Point 参数提供骨架 `x,y`；
- 灰字（ghost text）由宿主绘制，核心只提供文本。

---

## 13. 保留与未实现

- 关键字 `def` / `return` 保留；出现即报 S007。
- 未来扩展方向：用户函数（复用现有 callable 值模型）、模块、异常、插件注册、写时复制、增量解析、错误恢复。
- 明确不加：`as` 后缀转换、隐式数值字符串转换、多行字符串、块注释。

---

## 14. 图灵完备性

语言具备无界循环（`while`、`for`）、可变状态（变量、list、Point 分量）、条件分支，足以表达任意可计算过程；实际受 int64 与内存限制。

注意：int64 是有限精度，因此严格意义上不是无界整数模型。若未来需要真正的无界整数，应新增 `bigint` 类型而不是改变 `int` 语义。

## 16. EBNF 汇总

`NL` 为换行 token（受 2.2/2.3 抑制规则影响）。`word` 不是普通终结符，而是 3.4 切词后的 token 片段。

```ebnf
program     = { NL | ";" } { stmt ( NL | ";" | &EOF ) } EOF ;

stmt        = block
            | ifStmt
            | whileStmt
            | forStmt
            | breakStmt
            | continueStmt
            | refAssign
            | assignStmt
            | commandStmt ;

block       = "{" { NL | ";" } { stmt ( NL | ";" | &"}" ) } "}" ;
ifStmt      = "if" "(" expr ")" NL* stmt [ ( NL | ";" )* "else" NL* stmt ] ;
whileStmt   = "while" "(" expr ")" NL* stmt ;
forStmt     = "for" IDENT "in" expr NL* stmt
            | "for" "(" [ IDENT "=" expr ] ";" [ expr ] ";" [ expr ] ")" NL* stmt ;
breakStmt   = "break" ;
continueStmt= "continue" ;
refAssign   = IDENT "=" "ref" IDENT ;
assignStmt  = lvalue "=" expr ;
commandStmt = IDENT { word } ;

lvalue      = "*" IDENT
            | IDENT { "[" expr "]" | "." IDENT } ;   (* 后缀必须与前一项无空白 *)

word        = barePoint | expr ;                     (* 必须整词匹配 *)
barePoint   = simple ( "," simple ){1,2} ;           (* 2 或 3 个坐标 *)
simple      = "-"? atom suffix* ;
atom        = INT | FLOAT | IDENT | "(" expr ")" ;
suffix      = "[" expr "]" | "." IDENT | "(" [ expr { "," expr } ] ")" ;

expr        = ternary ;
ternary     = orExpr [ "?" expr ":" expr ] ;
orExpr      = andExpr { "||" andExpr } ;
andExpr     = eqExpr { "&&" eqExpr } ;
eqExpr      = relExpr { ( "==" | "!=" ) relExpr } ;
relExpr     = addExpr { ( "<" | "<=" | ">" | ">=" ) addExpr } ;
addExpr     = mulExpr { ( "+" | "-" ) mulExpr } ;
mulExpr     = unary { ( "*" | "/" | "%" ) unary } ;
unary       = ( "-" | "!" | "++" | "--" ) unary
            | "*" IDENT
            | postfix ;
postfix     = primary { "[" expr "]" | "." IDENT | "(" [ expr { "," expr } ] ")" | "++" | "--" } ;
primary     = INT | FLOAT | STRING | "true" | "false"
            | IDENT
            | "(" expr ")"
            | "(" expr "," expr [ "," expr ] ")"
            | "[" [ expr { "," expr } ] "]" ;
```

补充约束（EBNF 无法直接表达）：

1. 关键字、命令名、函数/类型构造器名大小写不敏感；
2. `IDENT` 在语句位置是命令名；在表达式位置是变量，或已注册函数/类型构造器的 callable 值；命令名出现在表达式位置 → S008；
3. `lvalue` 的后缀必须与前一 token 紧邻；
4. **所有后缀运算符**（`[...]`、`.IDENT`、`(...)`、`++`、`--`）都必须紧贴左操作数；
5. 调用时 callee 必须是 callable，否则 R012；
6. `word` 必须恰好消费切词得到的全部 token；
7. 语句之间必须有一个终止符，紧邻 `}` 的语句除外。

## 17. 待定与后续

以下事项不影响 v1 实现，但需要后续拍板：

1. 是否引入 `def` / `return` 及其参数传递规则（按值；引用参数是否用 `ref x`）；
2. 是否引入模块/import 与插件注册的生命周期；
3. 是否将 `point` 的维度约束扩展为 `point2` / `point3` 别名；
4. 是否为 list 增加切片、拼接与内建函数；
5. 是否引入错误恢复（一行错误不影响后续语句）；
6. 是否在补全中引入 tree-sitter 之类的外部增量解析（当前不需要）；
7. 用户函数如何复用现有 callable 值模型（定义、作用域、参数按值/ref）。
